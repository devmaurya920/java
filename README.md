Welcome to our shared coding space! We are developer friends from **India** 🇮🇳 passionate about computer science, problem-solving, and continuous learning. 

This repository serves as a centralized collection of foundational and advanced programming exercises in both **Java** and **Python** — covering:

Whether you are a beginner taking your first steps or someone brushing up on fundamentals, you are welcome to explore and contribute!

## 🛠️ Getting Started

Clone the repository to your local machine:

```bash
git clone https://github.com/devmaurya920/java.git
cd java
```

### Running Java Programs

Make sure you have JDK installed:

```bash
# Compile
javac JAVA/perfect_num.java

# Run
java -cp JAVA perfect_num
```

### Running Python Programs

Make sure you have Python 3.x installed:

```bash
# Run pattern generator
python PYTHON/pattern.py

# Run Armstrong number checker
python PYTHON/armstrong.py
```

## 🤝 How to Contribute

Contributions are what make the open-source community such an amazing place to learn, inspire, and create. Any contributions you make are **greatly appreciated**!

1. **Fork the Project** (click the `Fork` button at the top right of the repo)
2. **Create your Feature Branch**:
   ```bash
   git checkout -b feature/NewAlgorithm
   ```
3. **Commit your Changes**:
   ```bash
   git commit -m "Add: Binary Search implementation in Python"
   ```
4. **Push to the Branch**:
   ```bash
   git push origin feature/NewAlgorithm
   ```
5. **Open a Pull Request**:
   Go to the original repository and click **New Pull Request**.

> 💡 **Contribution Tip**: Add descriptive comments to your code and ensure variable naming is clean and readable!
